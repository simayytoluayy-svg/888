# Features

1. Play a 9x9 Sudoku puzzle with easy, medium, or hard difficulty.
2. Display the board with row and column separators and dots for empty cells.
3. Enter a number in an empty cell using row and column coordinates.
4. Reject a number that conflicts with an existing number in its row, column, or 3x3 box.
5. Protect the puzzle's original clue cells from changes.
6. Clear a number entered by the player.
7. Request a hint that fills the next empty cell with its solution.
8. Check whether the puzzle is incomplete, full but incorrect, or solved.
9. View entered numbers, remaining empty cells, invalid moves, and hints used.
10. Choose a difficulty again to start a fresh puzzle and reset the statistics.
11. Handle non-numeric input and validate menu choices and cell coordinates.
