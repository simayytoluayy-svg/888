# Sudoku Quiz

Sudoku Quiz is a Java console game for practicing classic 9x9 Sudoku. Choose easy, medium, or hard, enter and clear answers, request a hint, and track your progress with the game statistics.

## Author

Simay Toluay

The author's hobby is Sudoku.

## Run the project

Compile and run from the project directory with a Java Development Kit installed:

```text
javac src\Main.java
java -cp src Main
```

## How to play

Use the numbered menu to display the board, enter or clear a cell, check your solution, ask for a hint, or see your statistics. Rows and columns are numbered from 1 to 9. Original clue cells cannot be changed. Selecting a difficulty starts a fresh puzzle and clears the current statistics.

The program uses structured programming: one simple class, static methods, arrays, loops, and conditionals. It does not use inheritance, collections, or external libraries.
